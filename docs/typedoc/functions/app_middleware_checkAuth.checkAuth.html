    Function checkAuth

    • checkAuth(
          ...authRoles: Role[],
      ): (req: Request, res: Response, next: NextFunction) => Promise<void>

      Express middleware factory enforcing dual authentication and role-based authorization. Verifies BetterAuth active sessions, checks user active status in PostgreSQL, and validates signed JWT access tokens against allowed user roles.

      Parameters

      • ...authRoles: Role[]

        Whitelisted roles permitted to access the guarded route. Empty array permits any authenticated user.

      Returns (req: Request, res: Response, next: NextFunction) => Promise<void>

      Express middleware function (req, res, next)

      Throws

      401 UNAUTHORIZED if session/token is missing, expired, or invalid

      Throws

      403 FORBIDDEN if user status is BLOCKED/DELETED or role is not authorized

      Example

      router.post('/create-doctor', checkAuth(Role.ADMIN, Role.SUPER_ADMIN), UserController.createDoctor);
