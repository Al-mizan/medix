    Class QueryBuilder<T, TWhereInput, TInclude>

    Reusable fluent query builder for Prisma ORM models. Provides unified searching across relational fields, whitelisted filtering (exact, ranges, sets), dynamic pagination, sorting with nested relations, and relation inclusion.

    Example

    const result = await new QueryBuilder<Doctor, Prisma.DoctorWhereInput, Prisma.DoctorInclude>(
      prisma.doctor,
      req.query,
      { searchableFields: ['name', 'user.email'], filterableFields: ['appointmentFee'] }
    )
      .search()
      .filter()
      .paginate()
      .sort()
      .execute();
